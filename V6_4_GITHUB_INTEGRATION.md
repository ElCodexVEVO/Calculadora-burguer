# Integración V6.4 Spooky

Esta rama integra la identidad visual V6.4 de forma segura sobre la versión estable.

## Conservado
- Conexión existente de Supabase (config.js sin reemplazar).
- Anuncios RP y cupones existentes.
- Caja auxiliar, reportes, empleados, pagos y auditoría.
- Recursos del menú que ya están optimizados en assets/seasonal/menu/.

## Agregado
- Emblema spooky ligero en SVG.
- Capa visual spooky-v6.css.
- Cliente de la semana en el dashboard.
- Ajustes visuales de paneles, POS, navegación y animaciones.

La rama evita sustituir la base de datos o eliminar funciones actuales.
