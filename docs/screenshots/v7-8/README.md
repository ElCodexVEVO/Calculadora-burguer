# Capturas V7.8

Capturas reales de `DEMO_V6.html`, con datos simulados, tomadas durante la revisión del 12–13 de octubre de 2026. Cada JPG conserva origen, viewport CSS y dimensiones del bitmap en su sidecar JSON.

| Grupo | Viewport CSS | Vistas |
| --- | --- | --- |
| Escritorio | 1240 × 900 | Inicio, menú compacto, perfil, caja auxiliar y revisión de cobro |
| Móvil | 390 × 844 | Inicio, perfil y revisión de cobro |
| Tablet | 820 × 1000 | Perfil y caja auxiliar |

El proveedor de captura reduce ligeramente algunos bitmaps. Estas imágenes muestran el contenido completo de sus ventanas; no acreditan comparación pixel a pixel con la referencia de 1672 × 941. A ese tamaño se comprobaron únicamente las regiones mediante geometría DOM.

Las redes y las cifras mostradas son ejemplos locales. Las capturas no prueban el ciclo de fotografía entre dispositivos ni la aplicación publicada en `main`/Pages. Véase [validación](../../CINEMATIC_QA.md).
